# 投顧知識庫儀表板 · Investment Advisory Knowledge Hub

為投顧從業人員設計的每日知識庫儀表板，把分散在各大財經媒體的重點濃縮成可快速瀏覽的單頁網站，涵蓋美股與美國總經、台股、全球央行、AI／科技／金融／生技四大產業，以及地緣政治與美國政治。

## 主要來源

以下列五家為**主要來源**，並以公開／官方來源補充查證：

- **Bloomberg**、**WSJ 華爾街日報**、**NYT 紐約時報**、**FT 金融時報**（使用者本人正式訂閱，於自己登入的瀏覽器中合法存取）
- **華爾街見聞**（免費公開，且大量翻譯彙整西方財經報導）
- 公開／官方補充：Reuters 體系、CNBC、CBS、官方央行／交易所／公司 IR、政府與司法機構公告等

## 合規原則

- **不使用任何繞過付費牆或反爬蟲的手段**；付費內容一律以使用者本人訂閱、在其登入環境下閱讀。
- 公開頁面僅呈現**原創的重點摘要 ＋ 原文連結**，不轉載付費文章全文，以尊重來源方著作權與使用者訂閱權益。

## 更新架構（兩種模式）

| 模式 | 觸發 | 內容來源 | 何時用 |
|------|------|----------|--------|
| **每日自動版** | 每個交易日早上 07:30（台北）排程 | 公開來源＋華爾街見聞＋跨源搜尋 | 無人在場也會跑，穩定 |
| **加強版** | 使用者在場、瀏覽器已登入時手動觸發 | 加上 Bloomberg／WSJ／FT／NYT 四家訂閱全文重點 | 需要最完整內容時 |

- **內容產生**：由排程的 Claude 工作階段依 `AGENT_BRIEF.md` 的標準說明重生 `index.html`，commit 後推送至本 repo。
- **部署**：推送到 `main` 後，`.github/workflows/deploy.yml` 透過 GitHub Actions 自動部署到 GitHub Pages。

## 檔案結構

```
.
├── index.html                    # 儀表板單頁（含所有樣式與資料）
├── AGENT_BRIEF.md                # 每日重生內容的標準作業說明
├── README.md
└── .github/workflows/deploy.yml  # GitHub Pages 自動部署
```

本儀表板為新聞彙整與研究輔助工具，**非投資建議**。摘要為濃縮版本，可能遺漏原文細節或時間落差；數字引用前建議回查官方來源。地緣與市場變數方向可能快速反轉，請以最新一則與原始來源為準。
